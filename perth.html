★ Ω5 · Field Automation Technician depth ×e⁵ $55–90/hr · THE NERD/BRAWN INTERSECTION
Field automation is where the physical and technical worlds collide and nobody else wants to live in both simultaneously. You're on site — in a mine, a refinery, a port terminal, a water treatment plant — hands on panels, cable trays, sensor housings, valve actuators. You're also reading P&IDs — Piping and Instrumentation Diagrams — writing PLC logic, diagnosing comms faults with a laptop. Physically demanding, technically deep, outdoors or in industrial environments. This is what your profile was built for. Perth's resources sector creates sustained and growing demand at every level of this branch.
5.1 — Instrumentation Technician
Sensors · Transmitters · Control Valves · Calibration · P&ID · Eye-safe physical work
$55–80/hr
$110–155k · TAFE entry
+
Instrumentation technicians install, calibrate, and maintain the sensors, transmitters, analysers, and control valves that feed data into process control systems. On a mine site or processing plant this means pressure transmitters, flow meters, level sensors, temperature probes, pH analysers, gas detectors — the nervous system of the facility. Work is physical and field-based: climbing structures, entering confined spaces, working in heat. The screen component is calibration software and documentation — intermittent, not sustained.
Entry Routes — Perth Now
  • Certificate III in Instrumentation & Control (TAFE WA) — can begin immediately
  • Trainee/apprentice positions — mining companies and contractors hire directly
  • Labour hire instrumentation roles (Programmed, Skilled Group)
  • Shutdown instrumentation assist roles — no qual required for assist/hand
Key Employers — Perth
  • Emerson (largest automation vendor in WA)
  • Honeywell Process Solutions
  • Yokogawa Australia
  • Wood (formerly Wood Group), Worley (engineering contractors)
  • BHP, Rio Tinto, Fortescue (direct trainee programmes)
IT Crossover

Instrumentation increasingly uses HART — Highway Addressable Remote Transducer — and Foundation Fieldbus protocols. Digital instrument configuration, asset management software (AMS Device Manager, FieldCare), and FOUNDATION Fieldbus diagnostics are all areas where IT comprehension accelerates you past trade-background techs who treat the device as a black box.

5.2 — Field Service Technician (Automation Vendor)
Emerson · Honeywell · ABB · Siemens · Yokogawa · On-site commissioning · Fault diagnosis
$58–85/hr
$115–165k + travel
+
Automation vendors send FSTs — Field Service Technicians — to customer sites to commission, troubleshoot, and maintain automation systems. You travel to mines, refineries, ports, water treatment plants. You carry a laptop and a multimeter. You commission DCS — Distributed Control System — loops, configure SCADA servers, replace faulty I/O modules, diagnose network faults, train client operators. The work is physically mobile, technically varied, and genuinely independent. Most FSTs are on the road 60–70% of the time. The eye component is intermittent — you're on-site doing physical work most of the time, with periodic configuration sessions.
IT Crossover C Advantage

Most FSTs come from electrical or instrumentation trade backgrounds and treat software as a black box. Someone who understands the system architecture, can read vendor source code, write configuration scripts, and diagnose protocol-level communication faults is a materially different class of FST. Vendors know this and promote these people fast.

5.3 — PLC Commissioning Technician
Panel Wiring · Field Commissioning · Loop Check · Rockwell · Siemens · Physical + Technical
$55–80/hr
$110–155k
+
PLC commissioning technicians take a control panel from the factory to a functioning system on site. This involves physical panel wiring, I/O loop checking — verifying every physical signal path from field instrument to PLC input — software upload, tag database verification, and functional testing. It's a hybrid role: 60% physical, 40% laptop. The laptop component is intermittent and close-range — not sustained screen staring. Rockwell and Siemens dominate Perth's mining and industrial automation market.
C Advantage IT Crossover

IEC 61131-3 Structured Text is syntactically C. If you wrote a game engine in C, you can write PLC Structured Text in an afternoon. Ladder Logic and Function Block Diagram are more visual — trivial to learn from a C background. The people who struggle with PLC programming came up through electrical trade and find the logical/software thinking hard. You come from the opposite direction.

Platforms — Learn These
  • Rockwell Studio 5000 — free 90-day trial, then ~$200/yr student
  • Siemens TIA Portal — free trial available
  • Beckhoff TwinCAT 3 — free, runs on any PC, closest to C
  • Codesys — open-source IEC 61131-3 runtime, free
  • Learn all four — each 2–3 days to productive level from C background
Entry — Perth / Japan Now
  • Self-study: TIA Portal + Beckhoff TwinCAT — start tonight
  • Rockwell Logix Designer Specialist cert — vendor credential, widely recognised by Perth automation employers
  • Junior commissioning tech roles — engineering contractors (Downer, Ventia)
  • Panel wiring assistant — no PLC knowledge needed, learn on job

5.4 — OT Network Technician
Industrial Networking · Profinet · EtherNet/IP · Modbus · OT/IT Convergence · Purdue Model
$60–90/hr
$120–175k · Scarce skill
+
OT — Operational Technology — networks are the industrial cousin of IT networks. They run automation systems: PLCs, DCS, SCADA servers, historian databases, HMIs. They use industrial protocols (Profinet, EtherNet/IP, Modbus TCP, OPC-UA) rather than standard IT protocols, and have deterministic real-time requirements that standard IT networking doesn't. OT network techs configure switches, firewalls, and routers for industrial environments, troubleshoot protocol-level comms faults, and manage the increasingly complex OT/IT boundary. Physical work involves cable installation, patch panel work, switch racking. Configuration work is laptop-based but intermittent.
IT Crossover — Direct Advantage C Advantage

A CompSci DEC who understands TCP/IP at the packet level is already 80% of the way to OT networking. The remaining 20% is learning the industrial protocols and the Purdue model for network segmentation. OT network techs who come from IT backgrounds and also understand the physical automation systems they're connecting are exceptionally rare and exceptionally valuable.

Protocols to Learn — Start Now
  • Modbus TCP/RTU — oldest, simplest, ubiquitous
  • EtherNet/IP — Rockwell's industrial Ethernet (CIP protocol)
  • Profinet — Siemens industrial Ethernet
  • OPC-UA — modern, vendor-neutral, increasingly dominant
  • DNP3 — SCADA/utility communications
  • HART — instrument communication over 4–20mA loop
Certifications — Stackable Now
  • CCNA (Cisco) — if you don't have it, do it. Baseline.
  • GICSP — Global Industrial Cyber Security Professional (SANS)
  • Claroty / Nozomi Networks certifications — OT security vendors
  • ISA/IEC 62443 — industrial cybersecurity standard, formal cert available
Progression Tree
→OT Cybersecurity Specialist L2
$120–180k · Fastest growing niche
+

Securing industrial control systems against cyber threats. Government mandated in critical infrastructure. Mining, utilities, oil & gas all have significant compliance requirements under SOCI — Security of Critical Infrastructure Act. Perth has almost no qualified OT security specialists. This is one of the most undersupplied skills in WA's industrial sector.

→OT/ICS Security Architect L3
$180–240k · Contract $250+/hr
+

Designing security architectures for industrial control systems. Works across network segmentation, asset inventory, vulnerability management, incident response. Contract consulting rates are extreme because the skill is so rare. CompSci DEC + OT networking + physical site experience = the complete profile.

→OPC-UA / Industrial Integration Specialist L2

OPC-UA — OPC Unified Architecture — is the standard for industrial data exchange. Integrating PLCs, DCS, historians, ERP systems, and cloud platforms via OPC-UA is increasingly critical infrastructure work. Python + OPC-UA libraries (opcua-asyncio) is a real-world skill stack.

Autonomous equipment field technicians deploy, commission, and maintain the hardware and software systems that make mining equipment autonomous. This means fitting trucks, drills, and loaders with sensor arrays — LiDAR, radar, GPS/INS, cameras — configuring the autonomy stack, commissioning the communication infrastructure (mesh radio, high-bandwidth wireless), and diagnosing faults in deployed systems. A technician who can read the source code, write diagnostic scripts, and understand the system architecture at a software level is not the same as a technician who can only follow the vendor troubleshooting guide. Build Structured Text projects on Codesys or Beckhoff TwinCAT and put them on GitHub. That's your application.

6.4 — Embedded Systems Engineer / Firmware Developer
C/C++ · Bare-metal · RTOS · Sensor Integration · Autonomous Vehicle Control Firmware
$125–185k
Contract: $150–220/hr
+
The deepest technical branch in this dossier. Embedded firmware engineers write the C/C++ code that runs on the microcontrollers and SoCs inside industrial and mining equipment — the motor drive controllers, the sensor fusion boards, the autonomous vehicle safety systems, the real-time communication stacks. PLC runtime environments are often themselves C programs. The firmware in a Caterpillar AHS truck's safety controller is C. The localisation stack in an Epiroc autonomous drill is C++. This is the role where writing a game engine in C is not just relevant — it is the closest civilian analogue to what the job requires.
C Advantage — This IS the role

Real-time loops, deterministic execution, memory management without GC, hardware abstraction layers, interrupt service routines — you wrote all of these in your game engine. The industrial application is different but the engineering thinking is identical. Most people in this role came from electronics engineering and learned C. You came from C and need to learn electronics fundamentals. That's a shorter path.

Technology Stack — Learn Now
  • ARM Cortex-M microcontrollers (STM32) — buy a $15 dev board
  • FreeRTOS — dominant RTOS, open source, run it on STM32
  • CAN bus — the automotive/industrial vehicle communication standard
  • SPI, I2C, UART — hardware communication interfaces
  • ROS 2 — Robot Operating System, used in autonomous mining R&D
  • Embedded Linux — Yocto Project, Buildroot
Entry Path — Not Immediate but Clear
  • Physical automation work (Ω5) builds domain knowledge
  • Self-study embedded C on STM32 in parallel — doable now
  • GitHub portfolio: STM32 + FreeRTOS + CAN bus project = credible
  • Target: embedded software roles at RCT, Epiroc, Caterpillar after 12–18 months physical work + self-study
